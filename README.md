# foundry-modules

Modules for [Foundry VTT](https://foundryvtt.com) v14. To install one, paste its manifest URL into
Foundry's *Install Module* dialog; Foundry then offers updates by itself.

| Module | Version | Manifest URL |
|---|---|---|
| [Dewarim: File Commander](file-commander) | 0.2.0 | `https://raw.githubusercontent.com/dewarim/foundry-modules/main/file-commander/module.json` |
| [Dewarim: Image Drop](image-drop) | 0.1.1 | `https://raw.githubusercontent.com/dewarim/foundry-modules/main/image-drop/module.json` |
| [Dewarim: Item templates](items) | 0.1.0 | `https://raw.githubusercontent.com/dewarim/foundry-modules/main/items/module.json` |
| [Dewarim: Map Painter](map-painter) | 0.3.1 | `https://raw.githubusercontent.com/dewarim/foundry-modules/main/map-painter/module.json` |
| [Dewarim: Merchants](merchants) | 0.1.0 | `https://raw.githubusercontent.com/dewarim/foundry-modules/main/merchants/module.json` |
| [Dewarim: Studio](studio) | 0.1.0 | `https://raw.githubusercontent.com/dewarim/foundry-modules/main/studio/module.json` |
