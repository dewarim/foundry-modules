# foundry-modules

Modules for [Foundry VTT](https://foundryvtt.com) v14. To install one, paste its manifest URL into
Foundry's *Install Module* dialog; Foundry then offers updates by itself.

| Module | Version | Manifest URL |
|---|---|---|
| [Dewarim: Image Drop](image-drop) | 0.1.0 | `https://raw.githubusercontent.com/dewarim/foundry-modules/main/image-drop/module.json` |
