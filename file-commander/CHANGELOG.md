# Changelog

## 0.2.1 (2026-11-04)

- After an install or update, a GM sees what changed; *What's new* in the module settings shows the
  whole history.

## 0.2.0 (2026-10-17)

- **Where used**: below the preview, the documents that use a file - scenes (levels, tiles, tokens),
  actors (portrait, token, biography, items), journals.
- **Repoint**: *copy as* can move every reference to the new file in one go; earlier copies from the
  ledger can be repointed later.

## 0.1.0 (2026-10-17)

- Two-pane file manager for the user data: browse, filter, preview images, video and audio.
- Copy by drag and drop or F4, *copy as* (F6) to rename by copying, new folder (F7), upload from the
  desktop into a pane, drag an image onto the canvas for a tile.
- Copy only, by design: Foundry offers no move, rename or delete. Every copy is recorded in a ledger.
