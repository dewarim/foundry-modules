# Foundry module repositories by GitHub stars

Repositories that ship a `module.json`, from a search over the Foundry topics, keyword searches and a sweep of prolific module authors. Game systems, Docker images and type definitions are filtered out.

Stars measure developer attention, not users — see the overview for why install share is the better signal. Some popular modules are missing because they live on GitLab, build their manifest (so no `module.json` in the repo), or are closed-source premium modules.
