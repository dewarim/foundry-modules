# Research

Background research for module ideas. One dated folder per study, each with its own README stating
where the numbers came from and what they can be trusted to say.

- [foundry-module-popularity-2026-10-25](foundry-module-popularity-2026-10-25) — what Foundry users
  actually install (all 9,219 add-on modules by install share, a system-agnostic cut, GitHub stars
  and Hub endorsements), plus where rankings and reviews do and do not exist in the ecosystem.
